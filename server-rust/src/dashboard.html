PC Remote Rust

Kontrol PC ini dari Flutter melalui LAN atau Tailscale milik Anda.

Hubungkan HP

Pasang Tailscale resmi pada PC dan HP, login ke tailnet yang sama. Tidak perlu bergabung ke akun pengembang. LAN tetap bisa dipakai tanpa Tailscale.

Unduh Tailscale

Windows: aktifkan Run Unattended jika dibutuhkan. Key expiry dikelola pemilik melalui Tailscale. PC Remote tidak mengubah profil, DNS, SSH atau exit node Anda. Android hanya mendukung satu VPN aktif.

Koneksi

Server berjalan pada sesi Windows Anda. Sebelum login Windows, fitur desktop belum tersedia.
